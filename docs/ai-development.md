# AI-assisted development

AI assisted with requirements drafting, architecture exploration, application code, tests, debugging, and setup documentation. The product requirements specify PostgreSQL, React, annual/monthly CTC, configurable components, multiple currencies, and effective-dated increment history.

Working instructions included: preserve annual CTC as canonical; derive monthly equivalents using decimal arithmetic; enforce component reconciliation; reject stale concurrent edits; isolate automated tests from review data; verify CSV rollback and formula escaping.

Validation includes backend tests, browser workflows, lint, build checks, and documented setup checks. See [verification results](verification.md) and [test coverage](test-coverage.md) for recorded outcomes and limitations. AI output still requires developer review and understanding of the implementation. No real employee data was used.
