# Demo walkthrough

The application uses synthetic data only. Start the app and sign in with the local demo credentials in the README.

1. Show the 10,000-person directory and country/department filters.
2. Search for ACME-00001 and open compensation history. Compare annual components, monthly equivalents, and yearly increment percentages.
3. Open “Record salary change”. Show effective date, currency, CTC, and component editing. A mismatched component total is rejected without writing history.
4. Open compensation insights. Compare per-currency spend and medians; inspect the dated, illustrative INR planning conversion assumptions.
5. Show CSV import and its template, explaining that invalid rows roll back the whole import.
6. Sign out.

The automated browser recording in `docs/demo/walkthrough.webm` follows this workflow without changing existing salaries. Recreate it with `node frontend/scripts/record-demo.mjs` while the app is running on port 3100. It is a screen recording without narration. Screenshots are generated by the Playwright tests.
